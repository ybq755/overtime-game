# 加班牌局 OVERTIME

打工人卡牌肉鸽 · Steam 早期试玩原型（Web 版）

## 玩法
- 周一到周四搬砖攒分数，周五 BOSS 战
- 每天配额递增；情绪牌会传染，加班越久越焦虑
- 打出的牌进丢牌堆，丢牌堆循环回牌库——算牌是核心
- 通关每天从奖励牌里选 1 张构筑牌库

## 试玩
浏览器打开 **https://ybq755.github.io/overtime-game/** 即玩，无需安装，一局约 10 分钟。
